============================================================
  PDF 差异对比工具 5.0 · 使用说明书
============================================================

适用：PDF对比工具 5.0 Mac版 ／ Windows版（操作完全一样）

一句话：同一份文件的两个版本并排放进来，自动标出删了什么、加了
什么、哪一段挪了位置 —— 一个窗口看完，不用打印两张纸对着比。

功能一览
--------
输入   PDF ／ 图片（PNG JPG BMP TIFF）／ Word ／ Excel，能混着拖
选文件 拖两个按文件名排位（早的＝旧版）／「浏览…」多选／「清空」
       ／「⇅ 交换」
对比   开始 · 停止（不留半份结果）· 开跑前提示（默认开）
看结果 并排双栏 · 翻页缩放 · 删减(红)/新增(绿)/位移(浅蓝) 三图层
       · 底图灰度（只改显示）· 状态栏实时计数
导出   导出 JSON（页号 / 类别 / 文本 / 坐标）
安全   全程离线 · 不改原件


------------------------------------------------------------
一、四类输入，怎么比
------------------------------------------------------------

PDF（原生 / 转曲 / 扫描件 / 图文混排）、图片、Word（doc / docx）、
Excel（xls / xlsx）都能拖，也能混着拖（旧版 Word、新版 PDF 也行）。

  图片    先折成单页 PDF 再比
  Word    用本机 Word 另存成 PDF 再比（带完整文字层，走逐字比对）
  Excel   用本机 Excel 另存成 PDF 再比（同上）

PDF 内部装法不同，准不准差很远 —— 见第五节。

输出：一个窗口左右并排，差异直接画在页面上
  红色框   删减 —— 旧版有、新版没了
  绿色框   新增 —— 新版才有的
  浅蓝色框 位移 —— 内容一样、位置挪了（默认不显示）
  整页边框 页数不同时，多出来的整页画一圈


------------------------------------------------------------
二、怎么启动
------------------------------------------------------------

Mac      双击「PDF对比工具 5.0.command」。首次自动装依赖（联网一两
         分钟，只需一次）。提示「无法验证开发者」→ 右键点它 → 打开。
Windows  双击「PDF对比工具 5.0.bat」。需先装 Python 3.9+，装时勾
         「Add python.exe to PATH」。起不来先双击「运行前的环境准备.bat」。
         启动时先打一段自检（[ OK ] 全绿就是好的），然后自动开界面。

换电脑：整个文件夹一起拷，别只发 diff_app5.py（core、启动脚本、
setup_env.py、bootui.py 都必需）。


------------------------------------------------------------
三、怎么操作
------------------------------------------------------------

1）放文件：两份一起拖进顶部那个框，或一份一份拖，或点「浏览…」。
   按文件名自动排位，早的当旧版（与拖入先后无关）。
2）点「开始对比」。随时可点「■ 停止对比」中止。
   纯图片 / 扫描件 / 纯转曲会先弹确认框（见第四节）。
3）看结果：左右是同一页的新旧对照。跑完自动回第 1 页、按「适应宽度」。

放文件的几条规矩：
  拖第三个        默认挤掉旧版，留下「现有新版 + 刚拖的」
  重复拖已有的    不动，状态栏提示「这份已经在列表里了」
  「浏览…」       一次可选 1 个或 2 个，规则与拖放一样
  「清空」        两侧一起清（对比中不允许，先停止）
  「⇅ 交换」      排序反了手动对调

排序按文件名自然顺序：数字按数值比（rev2 在 rev10 前），所以
Picture.pdf 排在 Picture2.pdf 前面。


------------------------------------------------------------
四、结果怎么看 + 开跑前提示
------------------------------------------------------------

顶部图例：红＝删减（旧版）　绿＝新增（新版）　整页重绘＝画边框。

「位移」默认关：两版排版稍动一下就会进来几十条，一开就把真正的
删改淹掉了。要查「哪块被挪过」时再单独勾上。

底部状态栏右侧是分桶计数，如「旧版 PDF · 删减 3　新增 1」。数字
只统计当前勾选的那几类，跟画面是同一份数据。

「底图灰度」默认开：彩色原件配红绿标注太花，底图一灰标注就跳出
来。只改显示，判定结果一个字节都不受影响。

开跑前提示（「开始对比」右边的开关，默认开）
  点开始前，工具花零点几秒看一眼有没有文字层。只读文件、不识别、
  不改文件。会弹窗问一句的：
    · 纯扫描件、BarTender 标签这类整份没文字层的 PDF
    · 直接拖进来的 PNG / JPG / BMP / TIFF
    · 纯转曲，或文字大部分转成轮廓（转曲占八到九成以上）
  不弹窗的：Word / Excel（转出的 PDF 自带文字层）、转曲但留了完整
  隐形文字层的、只转了一小部分的、DWG 图文穿插但正文有文字的。

  弹窗按钮是「仍然对比 / 取消」。没有「以后不再提示」的勾 —— 点一
  下的时间远小于后面几分钟的等待。要长期关，用那个开关。


------------------------------------------------------------
五、准确性：先看属于哪一档（最重要的一节）
------------------------------------------------------------

不同 PDF 的可信度差得很远。原因不在算法，而在这份 PDF 里有没有
「能被直接读出来的文字层」。

A 档 · 原生（有完整文字层）
   逐字比对，差一个字就是一个框，位置准确。最快，一页几秒到几十秒。
   Word / Excel 转出来的 PDF 也在这一档。
   → 可以直接作为改版核对依据。

B 档 · 转曲但留了隐形文字层
   外观是轮廓，但搜一段已知文字能搜到。结果与 A 档同级，慢一倍。

C 档 · 纯转曲，或纯图片（扫描件、BarTender 标签、PNG）
   「部分有效」：
    · 真正改动的地方大体都能圈出来，不会整份静悄悄漏掉
    · 框是一整块一整块的，宽度差几个字正常；也有假差异和认错的字
    · 一页 100 秒到 600 秒不等，整页标签最慢
   → 当「提示器」用，帮你定位该人工看的区域，每条都要自己核。

自己判断：打开 PDF 按 Cmd+F（Windows 是 Ctrl+F）搜一段确定有的字。
   搜得到 → A 或 B 档，可信　　搜不到 → C 档，当提示器

一句话：对原生类极其有效；对转曲类和图片类部分有效 —— 能帮你把
「大概哪里变了」找出来，剩下的靠人眼确认。


------------------------------------------------------------
六、导出 JSON
------------------------------------------------------------

两份文件路径、耗时、每处差异的页号 / 类别 / 文本 / 坐标。默认名：

  PDF差异5.0_旧文件名_vs_新文件名_日期时间.json

给程序或留档用，不是给人读的报告；JSON 里不含图片。


------------------------------------------------------------
七、已知限制（实测出来的，不是推托）
------------------------------------------------------------

· BarTender / GRA 标签打出来的 PDF 是图像型的，没文字层，只能走
  C 档 —— 这是源头的输出方式，不是工具的问题。
· 纯扫描件（整页无文字层）目前可能一条差异都报不出来，先人工核对。
· 两版「转曲 / 文字」状态不一致会很吵：同一处内容旧版是图形、新版
  是文字，会被当成整段新增。噪音多，但真差异不会漏。
· 页数不同时，多出来的几页只画整页边框，不逐字比。
· 加密 / 带打开密码的 PDF 读不了，请先解密。
· Word / Excel 要靠本机 Office 转：没装就转不了。Mac 上第一次问一
  次授权，点「允许」；Word 里弹着对话框会转换失败，点掉再试。


------------------------------------------------------------
八、常见问题
------------------------------------------------------------

Q：双击没反应 / 窗口闪一下就没了？
A：没装 Python 3.9+。Windows 装时勾「Add python.exe to PATH」；
   Mac 去 python.org 下 3.9 以上版本。

Q：Windows 上图片 / 转曲部分一条差异都不标？
A：多半是 VC++ 运行库太旧，OCR 引擎加载不了（程序本身不报错）。
   装微软官方运行库 14.40 以上，装完必须重启电脑。

Q：跑了几分钟还没完？红绿框比文字宽很多？同一对文件两次条数不同？
A：都是 C 档（无文字层）的正常表现 —— OCR 慢、按块标不逐字、切分
   不稳定。随时可点「停止对比」，不会留下半份结果。

Q：只想看真正的删改，不想看位置变动？
A：确认「位移」是关的（默认关），只看红和绿。

Q：拖了 Word / Excel，报错或提示「系统没放行自动化控制」？
A：分平台看。
   Mac：系统设置 → 隐私与安全性 → 自动化，给「终端」勾上允许控制
   Microsoft Word / Excel，关掉工具重开。工具若从别的程序里代开，那
   种窗口拿不到授权 —— 自己双击启动器再跑。
   Windows：① 装的是 WPS 不是 Microsoft Office（只认后者）；
   ② Office 卡在对话框（只读 / 宏 / 启用编辑 / 登录），点掉再试；
   ③ 还报「失败」：把弹窗最后一行「完整技术日志：…」那个 txt 发
   过来，里面有完整调用栈。

Q：导出的 JSON 打不开？
A：它是 UTF-8 文本，用记事本或 VS Code 打开；浏览器直接打开会显示
   成一整段，是正常的。


------------------------------------------------------------
九、数据安全
------------------------------------------------------------

· 比对全程在本机离线完成：两份文件不上传、不联网。
· 唯一的联网动作是第一次启动时装运行依赖，之后不再联网。
· 工具不修改原件：只读两份文件、只在内存里画标注。
· 只有你主动点「导出 JSON」时才会写文件。
